1

What Fothering keeps, and for how long

Two different things are covered here. This website collects nothing about you. A Fothering deployment reads SES events in its operator's own AWS account, and it strips recipient addresses before anything is stored.

2

Every event passes one filter before it is stored

The ingest function sits between SES and the table. Fields that identify a person are dropped or turned into a domain and a keyed hash there, so the agent and the table never hold an address.

Field schedule for SES event records, as the ingest function will handle them.
SES fieldKeptStored
bounce.bouncedRecipients[].emailAddress, complaint.complainedRecipients[]ChangedThe receiving domain, plus an HMAC-SHA-256 of the lowercased address under a key kept in your account. A plain hash of an address can be reversed by guessing; a keyed one cannot without the key.
mail.destination, mail.headers, mail.commonHeadersDroppedNothing. Subjects and headers are not needed to name a cause.
bouncedRecipients[].diagnosticCodeChangedThe code with any address inside it removed, for example 550 5.1.1 user unknown. Receiving servers sometimes quote the address.
mail.tagsKeptConfiguration set and your own tags, which is how a cause is named. Do not put personal data in message tags.
bounceType, bounceSubType, complaintFeedbackType, timestamp, messageIdKeptAs sent by SES. None identifies a person.
3

Where, how long, and who decides

A deployment belongs to the business that deploys it. That business is the controller of its recipients' data; AWS processes it under that business's own AWS agreement.

Where

Everything stays in your AWS account in eu-central-1, Frankfurt. The model is called through Amazon Bedrock's EU inference profile, which keeps requests within EU regions.

How long

Event records and replies expire after 30 days. Expired records are removed within a few days after that, and are filtered out of every read in between.

Deleting

Forget one recipient from the console by entering their address: it is hashed with your key and every matching record is deleted. Deleting the stack removes everything.

This website

The pages you are reading are static files. They set no cookies and run no analytics.

  • Your theme choice, if you pick Light or Dark, is saved in your own browser and never sent anywhere.
  • Fonts are served from this site, not from a font service.
  • Cloudflare delivers the pages, and receives your IP address in order to do so, as any web host does.
  • The incident replay plays recorded data that ships with the page. It contains no real recipient.
